# 🔐 Security Policy

<div align="center">
Security guidelines for the Intelligent OCR project  
Responsible disclosure and safe collaboration
</div>

---

## 📌 Overview

<div>
The <strong>Intelligent OCR</strong> project is an open-source, educational and research-oriented prototype.
Security is important, even at the prototype stage, and we encourage responsible disclosure of any vulnerabilities.
</div>

This document describes:
- Supported versions
- How to report security issues
- What to expect after reporting
- Security considerations and limitations

---

## 🧩 Supported Versions

<div>
Only the latest version of the project is actively maintained.
</div>

| Version | Supported |
|-------|-----------|
| Latest `main` branch | ✅ Yes |
| Older releases | ❌ No |

Security updates and fixes will only be applied to the latest version.

---

## 🚨 Reporting a Vulnerability

<div>
If you discover a security vulnerability, please report it responsibly.
</div>

### ❗ Do NOT:
- Open a public GitHub issue
- Share exploit details publicly
- Test vulnerabilities on systems you do not own
